ФАМИЛЬЯ — как запустить

Нужен Node.js (nodejs.org, зелёная кнопка LTS). Больше ничего ставить не надо.

ВАРИАНТ 1. Нет общего Wi-Fi, у всех мобильный интернет
  1. Подключите ноутбук к интернету (например, раздайте с телефона).
  2. Дважды кликните ZAPUSK-INTERNET.bat.
     В первый раз он скачает программу cloudflared (около 60 МБ) — лучше
     сделать это заранее дома.
  3. Откроется стол в браузере. Через 10–30 секунд на нём появится QR-код
     со ссылкой вида https://...trycloudflare.com
  4. Друзья сканируют QR-код и заходят со своего мобильного интернета.
  Ссылка новая при каждом запуске.

ВАРИАНТ 2. Все в одной Wi-Fi сети (или раздаёте Wi-Fi с телефона всем)
  Дважды кликните ZAPUSK-WIFI.bat, друзья сканируют QR-код на столе.

Чёрное окно не закрывайте, пока идёт игра.
Стол: http://localhost:3001/table   Игроки: QR-код на столе.

Если у кого-то сел телефон — на столе есть кнопка «Ответить за…».
Картинки карт лежат в public/img — их можно заменить своими (то же имя файла).
